## AI tools

List each AI tool in `evaluation-manifest.json`, what it was used for and how the output was verified. Write `None` if no AI tool was used.

### ChatGPT
- **Used for:** Generating design mockups, planning application infrastructure, and architectural decisions for the vehicle service tracking system
- **Verification:** Manual review of design proposals and architectural patterns against project requirements

### Claude
- **Used for:** Code generation for components, backend APIs, database schemas, service calculation algorithms, and business logic implementation
- **Verification:** Manual testing of all generated code, running the application, and verifying functionality against requirements including testing all three service rule types

- **Used for:** Code completion, boilerplate generation, and assembling components in VS Code
- **Verification:** Line-by-line review in VS Code editor and functional testing of integrated code
